💓 Love AlarmYour Morning, Personalized.Love Alarm is a premium, open-source Android clock application that bridges the gap between the minimalist Stock Android aesthetic and deep, personal customization. While most alarm apps feel like a utility, Love Alarm feels like a companion.✨ Why Love Alarm?Most people hate their alarm sound. Love Alarm changes that by letting you wake up to the voices that matter or the songs you actually love, wrapped in a beautiful, bouncy Material Expressive interface.🎨 Material Expressive UIBuilt using the latest Material 3 (M3) guidelines, the app features:Dynamic Color (Material You): The entire app's theme shifts to match your wallpaper.Expressive Shapes: Oversized, organic buttons and fluid transitions that feel alive.Adaptive Layouts: Looks native whether you are on a compact smartphone or a tablet.🎙️ Personal TouchIn-App Voice Studio: Record a memo, a loved one’s voice, or a motivational note and set it as your alarm in two taps.Universal File Support: Don't be limited to ringtones. Pick any audio file directly from your device using the native File Manager.Stock Reliability: Built on the same logic as the AOSP/Google Clock to ensure your alarms actually go off, every time.🛠️ Features at a GlanceFeatureDescriptionVoice RecordHigh-quality .m4a recording directly in the alarm settings.Media PickerSeamless integration with Android's System File Picker.Adaptive UIFull support for Dark Mode and Material Expressive shapes.Smart SnoozeCustomizable snooze intervals with a "Stock" feel.🚀 Technical Deep DiveThis project is a showcase of modern Android development best practices:Language: 100% KotlinUI: Jetpack Compose with Material 3 Expressive components.Permissions: Minimalist approach—only asks for RECORD_AUDIO when you actually hit record.Architecture: Clean MVVM for easy testing and scalability.📥 Getting StartedClone: git clone https://github.com/YOUR_USERNAME/Love-Alarm.gitBuild: Open in Android Studio (Ladybug or newer recommended).Run: Compatible with Android 12 (API 31) and above for full Material You support.
